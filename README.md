# LumenResearch

> **Think in systems.**

A production-grade institutional research platform built for research institutions, universities, AI labs, analysts, think tanks, and scientific organizations.

## Live Demo

Deployed at: [lumenresearch.vercel.app](https://lumenresearch.vercel.app)

## Features

- **Loading Experience** — Animated LR monogram with progress animation
- **Auth System** — Sign In, Register, Forgot Password with LocalStorage session persistence
- **Landing Page** — Hero, Features, Pricing, Testimonials, Footer
- **Dashboard** — Stats widgets, activity charts, collaboration feed, AI insights
- **Workspace System** — Create, rename, archive, delete, switch workspaces
- **Paper Management** — Upload UI, drag & drop, search, filter, sort
- **AI Research Intelligence** — Insight engine, contradiction detection, trend analysis
- **Research Graph** — Animated interactive knowledge graph with concept mapping
- **Sandbox Simulation Lab** — Parameter controls, training charts, experiment logs
- **Team Collaboration** — Member management, shared workspaces, notifications
- **Analytics** — Publication velocity, citation trends, topic distribution
- **Settings** — Profile, Appearance, Notifications, Data Export, Institutional
- **Dark/Light Mode** — Smooth theme transitions
- **Mobile Responsive** — Bottom navigation, adaptive layouts

## Tech Stack

- HTML5
- TailwindCSS (via CDN)
- Vanilla JavaScript
- Chart.js
- LocalStorage (no backend required)

## Getting Started

Simply open `index.html` in a browser — no build step required.

Or serve it locally:

```bash
npx serve .
```
